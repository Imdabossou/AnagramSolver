# Contributing to Anagram Solver

Thanks for helping! A few things to know first.

- **Bugs and ideas:** open an issue. For a wrong or missing word, say which word list you were using and what you typed.
- **Word lists:** the lists are generated by `tools/build-words.sh` from public sources. Please don't edit `words/*.txt` by hand; change the script or its source instead.
- **Branches:** open pull requests against `development`. `main` only gets tested changes.
- **Checks:** the JavaScript, manifest and shell checks in [BUILDING.md](BUILDING.md) must pass, and the site must still serve every file through Docker Compose. CI runs both.
- **Keep it clean:** no ads, analytics, trackers, third-party scripts or build step.
- **Licence:** contributions are accepted under the project's licence (AGPL-3.0-or-later). Third-party code must be AGPL-compatible.
- **Security issues:** please report them privately, see [SECURITY.md](SECURITY.md).
